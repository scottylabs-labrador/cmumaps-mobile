# Mobile map uses react-native-maps

The phone draws the campus on Apple Maps for iOS and Google Maps for Android through react-native-maps. Building footprints, floor-plan rooms, and the route are polygons and polylines on that map. expo-maps can split the providers the same way, but it is still alpha and is absent from Expo Go. A single MapLibre map would have matched both platforms and would have looked unlike the website.
